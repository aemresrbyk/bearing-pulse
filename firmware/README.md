# Firmware (ESP32)

| Path | What |
|------|------|
| `lib/bearing_edge/` | Features (`features.c`) and Random Forest (`model.c`, generated by `src/train_edge.py`) in plain C99. Tested against the Python reference by `tests/test_edge.py`. |
| main sketch | Wi-Fi, ADXL345 reading, TLS MQTT publishing: **waiting for hardware** |

Credentials: copy `secrets.example.h` to `secrets.h` and fill in your Wi-Fi and MQTT details. `secrets.h` is git-ignored.
